SKN Pterodactyl Installer

Panel Installation > Ptero > Install now opens the Premium Pterodactyl Installer.

It collects:
- Panel Domain
- Admin Email
- Admin Username
- Admin Password
- Pterodactyl Panel version (20 listed releases)

The installer runs the community pterodactyl-installer for the system dependencies and panel setup, then checks out the selected Pterodactyl release and refreshes Composer/database/application caches.

Current upstream Pterodactyl releases are tracked here:
https://github.com/pterodactyl/panel/releases

Note: the pterodactyl-installer.se script is a third-party installer and is not the official Pterodactyl project installer.
