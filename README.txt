SKN Pterodactyl Installer - New Menu

Run:
  chmod +x skn-pterodactyl-installer.sh
  sudo ./skn-pterodactyl-installer.sh

Menu:
[1] Panel Installation
[2] Wings Installation
[3] Themes
[4] Extensions
[5] Cloudflare Setup
[6] System Information
[7] Database Setup (Coming soon)
[0] Exit

Invalid input never exits the script. Valid menu choices show a loading animation first.

The Panel/Wings installation action uses the current community Pterodactyl installer
endpoint documented by its upstream repository. Themes, Extensions, Cloudflare and
Database are UI modules/placeholders in this build and do not make destructive changes.
